# Fitness Planner AI (Backend)

Интеллектуальная гибридная система для составления персонализированных тренировочных планов. Проект сочетает в себе детерминированные алгоритмы фильтрации (Python) и семантический анализ текста (LLM Groq/Llama 3.1).

## 🚀 Ключевые особенности (Архитектура)

- **Neuro-Symbolic Logic:** Разделение ответственности между алгоритмом (безопасность, сплит-системы, инвентарь) и нейросетью (анализ жалоб пользователя, эмпатия).
- **RAG (Retrieval-Augmented Generation):** Генерация планов на основе локальной базы знаний (JSON-каталоги), что исключает галлюцинации ИИ.
- **Интеллектуальный NLP-анализ:**
    - **Pre-workout Check-in:** Анализ текущего состояния и болей пользователя перед тренировкой для мгновенной адаптации плана.
    - **Post-workout Feedback:** Обработка отзывов для формирования долгосрочного черного списка упражнений.
- **Циклическая сплит-система:** Автоматическое чередование мышечных групп (Push-Pull-Legs) с сохранением состояния в БД.
- **Строгий фильтр инвентаря:** Исключение упражнений, не соответствующих текущему оборудованию пользователя (Свой вес / Гантели / Зал).

## 🛠 Технологический стек

- **Framework:** FastAPI (Python)
- **Database:** SQLite + SQLAlchemy ORM
- **AI Integration:** Groq API (Model: Llama 3.1 8B)
- **Architecture:** REST API, RAG, NLP
