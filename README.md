# Fitness Planner AI Backend

Бекенд для дипломного проекта: Система индивидуализированного планирования тренировок.

## Стек технологий
- Python 3.10+ / FastAPI
- PostgreSQL
- YandexGPT API

## Инструкция по запуску
1. Создать виртуальное окружение: `python -m venv venv`
2. Активировать окружение: `venv\Scripts\activate`
3. Установить зависимости: `pip install -r requirements.txt` (файл добавим позже)
4. Запуск сервера: `uvicorn app.main:app --reload`
